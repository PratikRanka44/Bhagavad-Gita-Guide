# 🕉️Bhagavad Gita Guide

A RAG-based application that grounds real-life guidance in the Bhagavad Gita. Describe a situation you're facing or ask a genuine reflective question about life, happiness, or human nature and it retrieves a real, relevant verse in Sanskrit (with transliteration), and explains how it applies, in Hindi, English, or Marathi.

Inspired by watching *Kurukshetra* on Netflix and wanting to explore whether an LLM pipeline could do, in a small way, what Krishna does for Arjuna: meet a real situation with a specific, grounded teaching rather than generic advice.

**[Live demo →](#)** *https://bhagavad-gita-guide.streamlit.app/*

## Why this project

Most "ask an AI about ancient wisdom" tools have a reliability problem: LLMs frequently misquote scripture — wrong verse numbers, invented Sanskrit, blended quotes. This project is built around a deliberate constraint: **the model never generates the source text.** Sanskrit, transliteration, and translations are always retrieved verbatim from a verified dataset; the LLM only writes the situational explanation layered on top. Retrieval and generation are kept strictly separate for exactly this reason.

## Features

- **Full corpus** — all 719 verses across all 18 chapters of the Bhagavad Gita, in Sanskrit, IAST transliteration, Hindi, and English
- **Multi-stage agent pipeline** — scope check → semantic retrieval → verse selection → grounded response generation, rather than one monolithic prompt
- **Handles both personal situations and philosophical questions** — "I'm scared to leave my job" and "what is the meaning of happiness" are both in scope; math, trivia, and off-topic requests are politely declined rather than forced onto an unrelated verse
- **Trilingual output** — responses generated in English, Hindi, or Marathi, selectable per query (Marathi is grounded off the verified Hindi translation rather than a dedicated Marathi verse dataset — see [Data & Attribution](#data--attribution))
- **Semantic, cross-lingual retrieval** — multilingual sentence embeddings match a user's input (in English, Hindi, or Marathi) against verse meaning and themes, not keyword overlap
- **Verified data provenance** — verse text sourced from an open, citable dataset (see [Data & Attribution](#data--attribution)), not generated by an LLM
- **Bhagavad Gita-themed UI** — dusk-indigo palette, a manuscript-style card for the retrieved verse, optional looping background music

## How it works

```
User's input
       │
       ▼
┌─────────────────────┐
│ 1. Scope classifier  │  A real situation or reflective question? Or off-topic
└─────────────────────┘  (math, trivia, small talk)? → if off-topic, decline
       │
       ▼
┌─────────────────────┐
│ 2. Retriever          │  Multilingual embedding search over verse
└─────────────────────┘  translations + themes → top-k candidates
       │
       ▼
┌─────────────────────┐
│ 3. Verse selector     │  LLM picks the single best-fit verse from
└─────────────────────┘  the candidates only (never invents one)
       │
       ▼
┌─────────────────────┐
│ 4. Response composer  │  Generates a short, grounded explanation in
└─────────────────────┘  the chosen language — verse text is never
                          regenerated, always pulled from the dataset
```

## Tech stack

| Layer | Choice |
|---|---|
| LLM inference | [Groq API](https://console.groq.com) (`openai/gpt-oss-120b`) |
| Embeddings | `sentence-transformers` (multilingual, model configurable) |
| Retrieval | Cosine similarity over verse embeddings (NumPy) |
| UI | Streamlit |
| Data | Verified open dataset, cleaned into a custom JSON schema |

## Getting started (local)

### Prerequisites
- Python 3.10+
- A free [Groq API key](https://console.groq.com)

### Installation

```bash
git clone https://github.com/<your-username>/gita-guide.git
cd gita-guide
pip install -r requirements.txt
```

### Configuration

```bash
export GROQ_API_KEY=gsk_...          # macOS/Linux
$env:GROQ_API_KEY = "gsk_..."        # Windows PowerShell
```

### Run

```bash
streamlit run app.py
```

Or test from the terminal without the UI:

```bash
python test_pipeline.py
```

## Example

**Input:** *"I'm scared to leave my stable job and start my own business."*

**Output:** Bhagavad Gita 18.8 — with the Sanskrit, transliteration, and a short explanation connecting the verse's teaching on fear and avoidance of duty to the specific situation described, in the selected language.

**Input:** *"What is the meaning of happiness?"*

**Output:** A relevant verse on the Gita's distinction between fleeting sensory pleasure and lasting inner contentment, with a direct answer to the question — not just advice for a "situation."

## Deploying to Streamlit Community Cloud

This makes the app publicly usable at a shareable URL, for free.

1. **Push this repo to GitHub** (public, or private if you're on a plan that supports it).
2. Go to [share.streamlit.io](https://share.streamlit.io) and sign in with GitHub.
3. Click **"New app"**, select this repository, branch `main`, and set the main file path to `app.py`.
4. Before deploying, open **"Advanced settings"** and add your secrets in the **Secrets** field, in TOML format:
   ```toml
   GROQ_API_KEY = "gsk_..."
   GITA_EMBEDDING_MODEL = "paraphrase-multilingual-MiniLM-L12-v2"
   ```
   Root-level keys here are automatically available both as `st.secrets["KEY"]` *and* as regular environment variables — which is what this project's code reads from, so no code changes are needed.
5. Click **Deploy**. First boot will take a few minutes (installing dependencies, downloading the embedding model).

### ⚠️ About the `GITA_EMBEDDING_MODEL` line above

Streamlit Community Cloud apps are capped at **1GB of RAM**. This project's default embedding model (`paraphrase-multilingual-mpnet-base-v2`) is roughly 1GB in memory on its own — it will likely push a deployed app over that limit and crash. Setting `GITA_EMBEDDING_MODEL` to the lighter `paraphrase-multilingual-MiniLM-L12-v2` model (~470MB) as shown above avoids this, at a small cost to retrieval nuance. If you're deploying somewhere with more memory headroom (your own server, a paid tier, etc.), you can drop that line and use the default model instead.

### Other things to check before deploying publicly
- Make sure `.streamlit/secrets.toml` is **not** committed (it's in `.gitignore` — double check it's not already tracked if you created it before adding the ignore rule)
- If you added `assets/background.mp3`, confirm it's a properly licensed royalty-free track (see `assets/README.md`) before making the repo public
- Consider your Groq API usage limits if the app gets real traffic — see [console.groq.com](https://console.groq.com) for your tier's rate limits
